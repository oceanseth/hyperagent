02 / What the stack makes possible

The integration is the experience.

01 — RESEARCH

Answers with
a place to live.

Exa brings back live evidence. Mastra works through it. The Fly.io worker publishes into Neon, and Assistant UI makes the results readable on the shared canvas.

02 — ACTION

Watch the work.
Keep the context.

KERNEL puts a live browser on the board. Executor connects the tools. A background agent acts in that same session, so teammates can see the work as it happens.

03 — CONTINUITY

Agents with
somewhere to return.

Neon stores the shared workspace and routes inference. AgentMail gives configured agents their own inboxes. Optional Mastra memory brings earlier formation context into the next turn.
